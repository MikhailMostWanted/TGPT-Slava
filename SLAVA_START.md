# Славе: запуск TGPT с нуля

Нужен **собственный VPS с Ubuntu**, SSH-доступ, домен/поддомен с A-записью на этот VPS, свой GitHub и Telegram. На VPS не должно быть чужих Telegram-сессий. Установленный Codex может работать локально по SSH либо прямо на VPS.

## 1. Что подготовить

- Собственный домен (например `tgpt.example.com`) с DNS на IP VPS.
- `api_id` и `api_hash` в https://my.telegram.org → API development tools. Это не токен Telegram-бота.
- Собственный GitHub OAuth App: https://github.com/settings/developers → New OAuth App. Homepage URL = `https://ТВОЙ-ДОМЕН`; Authorization callback URL = `https://ТВОЙ-ДОМЕН/auth/callback`. Получи Client ID и Client Secret.
- **Числовой** GitHub ID Славы: если установлен GitHub CLI, `gh api user --jq .id`; либо открой `https://api.github.com/users/ТВОЙ_ЛОГИН` и найди поле `id`. Это не логин.
- Собственный телефон Telegram; код входа и 2FA-пароль потребуются только на этапе авторизации.

**Не присылай секреты Codex/ChatGPT в сообщениях** и не коммить их. Вводи их лично через скрытый ввод (`getpass`) на сервере.

## 2. Готовый запрос Codex — вставить целиком в пустой папке

> Я Слава. Хочу запустить **свою** независимую копию TGPT (read-only MCP для собственного Telegram) на моём VPS и подключить её к ChatGPT Plus.
>
> Репозиторий: https://github.com/MikhailMostWanted/TGPT-Slava
>
> Ты находишься в пустой рабочей папке. Сначала клонируй репозиторий **в текущую папку** командой `git clone https://github.com/MikhailMostWanted/TGPT-Slava.git .`. Если папка оказалась не пустой, безопасно разберись с этим, не удаляя чужие файлы.
>
> Прочитай `AGENTS.md`, `README.md`, `DEPLOY.md` и `CHATGPT_HANDOFF.md` полностью; используй код репозитория как основу, **не переписывай проект с нуля**. Не используй чужие серверы, Telegram-сессии и секреты. Выполни проверку безопасности и тесты.
>
> Дальше помоги развернуть всё на **моём собственном VPS**. Если Codex не находится на VPS, сначала проверь, есть ли у тебя законный и работающий SSH-доступ к нему; при отсутствии доступа дай точные команды мне и не выдавай локальную установку за развёрнутый VPS. Проверь Docker Engine, Compose v2, Buildx; при необходимости установи их из официального источника. Настрой личный HTTPS-домен через Caddy, но только если порты 80 и 443 свободны; иначе используй уже имеющийся reverse proxy, ничего не ломая.
>
> Собери контейнер, создай отдельные защищённые `config/` и `data/`, проведи `docker compose run --rm -it setup init` и `setup login`. Для Telegram API ID/Hash, GitHub OAuth Client ID/Secret, числового GitHub ID, номера, кода и 2FA **не проси меня публиковать значения в чате** — организуй ручной ввод в терминале, не логируй секреты. GitHub ID не должен быть Михаила и не должен оставаться значением по умолчанию. Вход в Telegram должен быть только в **мой** аккаунт.
>
> Подними `reader` и HTTPS. Проверь локальный `/healthz`, публичный HTTPS, OAuth discovery и что неавторизованный запрос к `/mcp` получает 401. Для проверки чатов используй только явно выбранные мной безопасные примеры. В ChatGPT объясни, как зайти в Plugins → «Добавить собственный MCP-сервер», указать `https://МОЙ-ДОМЕН/mcp`, выбрать OAuth/DCR, пройти вход через **мой** GitHub и установить плагин. Если такой пункт недоступен в моём Plus, честно объясни ограничение аккаунта/интерфейса, не отключая защиту.
>
> При неполадках исправляй **причину**, затем повторно запускай тесты. Никаких платных OpenAI API, фоновой индексации переписок, отправки сообщений и глобальных чисток Docker. Финальный отчёт: публичный адрес MCP, статус контейнеров и HTTPS, что реально проверено, какие шаги остались за мной. Не показывай секреты, конфигурацию или содержимое переписок.

## 3. Минимальные команды для ручного оператора

На VPS:

```bash
git clone https://github.com/MikhailMostWanted/TGPT-Slava.git
cd TGPT-Slava
sudo install -d -m 700 -o 10001 -g 10001 config data
bash scripts/build.sh local
docker compose run --rm -it setup init
docker compose run --rm -it setup login
```

Затем следуй `DEPLOY.md` (HTTP-прокси и HTTPS). Номер, код и 2FA вводятся в терминале **без эха**, не в переписке с ИИ.
